<h2 align="center">Full-Stack & AI Engineer | Founding iOS Engineer @ TwinMind

I'm a software engineer with a strong foundation in Swift/SwiftUI and 
growing full-stack expertise across React Native, Python, and Node.js. 
I specialize in building AI-powered consumer applications — from 
early-stage products to production apps used at scale.

🚀 Experience

As founding iOS engineer at TwinMind (an AI meeting notes/memory app), 
I helped scale the product significantly, working across the full stack 
of mobile engineering: real-time systems, CloudKit & SwiftData, Firebase 
auth, background task architecture, RAG pipelines, and Swift 6 strict 
concurrency. I built an AI Mouse system for LLM-controlled iPhone 
automation, local-first architectures with optimistic UI and undo 
systems, and shipped subscription flows, onboarding, and calendar 
integrations end-to-end.

Beyond TwinMind, I've shipped and contributed to several AI-powered 
mobile apps: xOneAI, Skarvo, Pheezee, and Ideaverse — covering 
everything from architecture design to production debugging and CI/CD.

🎸 Currently Building

Advance — a tour management platform for the live music industry, 
built with React Native, Expo, and Supabase. This project spans the 
full stack: backend architecture with Row-Level Security, PDF 
ingestion pipelines, email-to-database systems, invitation/deeplink 
flows, and frontend state management with Zustand.

🃏 Side Projects & Interests

Poker training tools (range viewers, GTO/CFR solver exploration), 
iOS automation, and startup branding/naming. I've also cross-trained 
extensively between Swift/SwiftUI and React Native/Python — building 
side-by-side comparisons of hooks vs. property wrappers, MVVM patterns, 
and navigation architectures to deepen my full-stack fluency.

💡 What I Bring

- Production experience shipping and scaling consumer AI apps
- Strong systems thinking: real-time architecture, offline-first design, 
  concurrency, and data pipelines
- Full-stack range: iOS native, React Native, backend (Node.js, Supabase), 
  and AI/LLM integration (RAG, prompt engineering, automation)
- A builder's mindset — I like owning problems end-to-end, from database 
  schema to UI polish</h2>
